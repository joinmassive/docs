---
title: "Geohash targeting"
description: "A request can be targeted at an area on the map by its geohash."
---

A [geohash](https://en.wikipedia.org/wiki/Geohash) is a short code for a rectangular area on the map. The `geohash` parameter selects nodes inside that area.

```bash
curl -x https://network.joinmassive.com:65535 \
     -U '{PROXY_USERNAME}-geohash-dr5r:{API_KEY}' \
     https://cloudflare.com/cdn-cgi/trace
```

| Characters | Area, approx.  | Example           |
| ---------- | -------------- | ----------------- |
| 1          | 5000 × 5000 km | `d`               |
| 2          | 1250 × 625 km  | `dr`              |
| 3          | 156 × 156 km   | `dr5`             |
| 4          | 39 × 20 km     | `dr5r` (New York) |

Node locations are approximate, so longer codes match fewer nodes.

## Options

- `geohashnear` adds the 8 surrounding areas of the same size: `-geohash-dr5r-geohashnear`. It applies to a single code.
- Up to 5 codes can be listed: `-geohash-dr5r,dp3w`.
- `country` is optional and limits the area to one country: `-country-US-geohash-dp`.
- `subdivision`, `city` and `zipcode` cannot be combined with `geohash`.
- As with [other geo parameters](/residential/geotargeting#targeting-multiple-locations), only one parameter may hold a list; `geohashnear` counts as a list.

A request with an invalid code or combination returns 400; a request with no available node in the area returns 471.
