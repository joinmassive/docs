---
title: "Geohash targeting"
description: "A request can be targeted at an area on the map by its geohash."
---

A [geohash](https://en.wikipedia.org/wiki/Geohash) is a short code for a rectangular area on the map. The `geohash` parameter selects nodes inside that area.

```bash
curl -x https://network.joinmassive.com:65535 \
     -U '{PROXY_USERNAME}-geohash-dr5r:{API_KEY}' \
     https://cloudflare.com/cdn-cgi/trace
```

| Characters | Area, approx.  | Example           |
| ---------- | -------------- | ----------------- |
| 1          | 5000 × 5000 km | `d`               |
| 2          | 1250 × 625 km  | `dr`              |
| 3          | 156 × 156 km   | `dr5`             |
| 4          | 39 × 20 km     | `dr5r` (New York) |

Sizes are at the equator; areas get narrower toward the poles. Codes are case insensitive.

Node locations are approximate. A node located only roughly matches short codes but not long ones, so a 4-character code can return 471 where its 3-character parent finds nodes.

## Options

- `geohashnear` also includes the 8 surrounding areas of the same size: `-geohash-dr5r-geohashnear`.
- `geohashfallback` returns the nearest available node instead of 471: `-geohash-dr5r-geohashfallback`. The search moves outward from the area, then to the whole country. Other parameters still apply. Codes longer than 4 characters are shortened to 4.
- Both work with a single code and need no value; `-on` and `-off` are also accepted.
- Up to 5 codes can be listed: `-geohash-dr5r,dp3w`.
- `country` is optional and limits the area to that country, which helps near borders: `-country-US-geohash-dp`.
- [`asn`](/residential/asn-type-targeting) and [`type`](/residential/device-type-targeting) can be added: `-geohash-dr5r-asn-7922`.
- `subdivision`, `city` and `zipcode` cannot be used with `geohash`.
- Only [one parameter may hold a list](/residential/geotargeting#targeting-multiple-locations); `geohashnear` counts as one.

<Warning>
  With `geohashfallback` and no `country`, the exit node can be in any country.
</Warning>

## Behavior

- A [sticky session](/residential/sticky-sessions) stays inside the area. If its node leaves, the session moves to another node in the area; with `sessionmode-norotate` the request returns 475. With `geohashfallback`, it is limited only by `country`.
- An invalid code or combination returns 400. 471 means no available node in the area; with `geohashfallback`, no matching node in the whole country, or anywhere when no country is given.
- The [`X-Exit-Geohash`](/residential/exit-node-headers#x-exit-geohash) header of the CONNECT response shows the exit node's area. With `geohashfallback` it can differ from the requested code, and it is absent when the node's location is known only to the country.
